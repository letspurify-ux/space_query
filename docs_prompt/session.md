oracle oci/thin, mariadb, mysql 모두에서 세션 누수 버그가 있을지, 추가로 필요한 테스트가 있을지 검토해줘.
disconnect되면 관련 세션이 모두 종료되도록 보장해야 해.
관련 쿼리 tab이 닫히면 관련 세션이 모두 종료되도록 보장해야 해.
미아가 된 세션도 모두 종료되도록 보장해야 해.
버그가 발견되면 공통 구조로 4개 db 모두에서 보장되도록 개선해줘.
의심되는 경우에만 테스트 케이스를 추가해줘.
테스트할 때는 도커 이미지를 하나씩만 띄워줘. 메모리가 부족해.
모든 테스트 케이스가 oracle oci/thin, mariadb, mysql에서 모두 정상 동작하는 것이 보장되어야 해.
결과는 테이블 형태로 정리해서 최종 보고해줘.
row는 테스트 케이스, col은 oracle oci, thin, mariadb, mysql로 구분해줘.
